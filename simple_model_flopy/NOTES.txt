FloPy / MODFLOW 6 environment
=============================

Create and activate the Conda environment:

  conda create -n mf6 -c conda-forge python=3.12 flopy vtk pyvista matplotlib numpy pandas jupyterlab
  conda activate mf6

Generate the MODFLOW 6 input files locally (does not run the model):

  python scripts/build_model.py

Transfer the generated files to the remote server and submit:

  qsub run_mf6.sh

Post-process a successful run:

  python scripts/plot_results.py
  python scripts/export_paraview.py

Source files
------------

  scripts/build_model.py       Complete FloPy model definition and input writer
  scripts/plot_results.py      Head statistics and map generation
  scripts/export_paraview.py   Head and specific-discharge VTK export
  run_mf6.sh           PBS/HPC script that runs mf6 directly
  README.md            Model definition and usage documentation

The *.nam, *.tdis, *.ims, *.dis, *.ic, *.npf, *.chd, *.rcha, *.wel, and
*.oc files are generated in model_input/ by scripts/build_model.py. MODFLOW 6
writes binary heads and budgets to model_output/ and listing files to
model_input/.
