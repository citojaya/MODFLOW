FloPy / MODFLOW 6 environment
=============================

Create and activate the Conda environment:

  conda create -n mf6 -c conda-forge python=3.12 flopy vtk pyvista matplotlib numpy pandas jupyterlab
  conda activate mf6

Generate the MODFLOW 6 input files locally (does not run the model):

  python build_model.py

Transfer the generated files to the remote server and submit:

  qsub run_mf6.sh

Post-process a successful run:

  python plot_results.py
  python export_paraview.py

Source files
------------

  build_model.py       Complete FloPy model definition and input writer
  plot_results.py      Head statistics and map generation
  export_paraview.py   Head and specific-discharge VTK export
  run_mf6.sh           PBS/HPC script that runs mf6 directly
  README.md            Model definition and usage documentation

The *.nam, *.tdis, *.ims, *.dis, *.ic, *.npf, *.chd, *.rcha, *.wel, and
*.oc files are generated by build_model.py. Binary outputs and listing files
are generated by MODFLOW 6.
